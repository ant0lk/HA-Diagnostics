# Установка и использование

1. Из пакета `dist/ha-addons` перенесите только выбранную папку приложения в `/addons/` HA OS. Нужен доступ владельца к локальным приложениям HA; эти файлы не читаются продуктом в runtime.
2. Обновите магазин приложений, установите Import, оставьте Protected mode включённым и откройте панель через Ingress.
3. Импортируйте `.log`, `.txt` или `.json`, проверьте очищенный предпросмотр и отдельно разрешите удалённое чтение.
4. Для live-данных требуется отдельный Live alpha профиль, ручной выбор источников/сущностей и приёмка реальных прав/изоляции. Manager не является ролью чтения.
5. Транспорт выключен до локальной настройки. Секреты вводятся локально, никогда не отправляются в ChatGPT и не входят в пакет плагина.

Для полного runbook используйте `docs/INSTALL.md` из исходной поставки. Удалённый доступ отзывается в локальной панели; удаление плагина из ChatGPT не заменяет локальный отзыв.
