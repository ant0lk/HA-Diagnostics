# HA-Diagnostics 1.0.0-alpha.7

Умный дом Яндекса подключается в панели отдельно: OAuth-токен с правом чтения `iot:view`, включение сбора, интервал и срок хранения. По умолчанию все устройства проверяются раз в 60 секунд, история хранится 30 дней; настройки действуют без перезапуска, панель можно закрыть. Накопленная история online/offline, восстановления и пропуски наблюдения сохраняются между перезапусками и попадают в каждый ручной/ежедневный ZIP в `yandex/`. Токен хранится приватно и исключён из ZIP; названия и ID устройств заменяются устойчивыми псевдонимами. История начинается после подключения, время перехода ограничено интервалом между проверками. Ошибка API даёт unknown, а не offline. Демо не подключается к реальному аккаунту; чтение Яндекса и работа на HA OS требуют приёмки. Подробнее: `docs/ZIP_EXPORT.md`, раздел «Умный дом Яндекса».

Alpha 5 добавляет трассы автоматизаций/скриптов, Repairs, уведомления, System Health/System Log, диагностику устройств, этажи/метки, задания/репозитории Supervisor, службы хоста, диск/swap и статистику Recorder (до 64 рядов за 7 дней). В configuration входят используемые blueprints, YAML-панели и буквальные Jinja-импорты без исполнения. system/overview.json и .txt содержат паспорт хоста: ресурсы ядра отдельно от контейнерных лимитов, версии, оборудование, сеть и дополнения. comparison/ сравнивает настройки, установленные версии и реестры с предыдущим сохранённым ZIP, включая Alpha 4. Недоступные данные и пределы сбора отражаются в manifest; фоновое накопление событий/нагрузки HA не включено.

Основной Live-профиль собирает и скачивает диагностический ZIP без MCP/OAuth/Tunnel: доступные журналы и сведения об установке, история и события за последние 24 часа. См. `docs/ZIP_EXPORT.md`.

Предварительный частный alpha-пакет. Import-профиль не удерживает credentials HA и работает с локально импортированными очищенными файлами. Live-профиль поставляется отдельно; у его broker широкий токен Supervisor manager, и реальные HA OS/ChatGPT проверки ещё нужны.

Сначала выполните `python scripts/package_release.py`: он создаст самостоятельный build context в `dist/ha-addons/`. Исходная папка приложения без staged `app/` не является готовым контекстом Docker.

Полная установка, настройка, отзыв и ограничения: `docs/INSTALL.md`, `docs/LIVE_ACCEPTANCE.md`, `docs/SECURITY.md` в исходной поставке. Не отключайте Protected mode. Домашние порты открывать не требуется.
