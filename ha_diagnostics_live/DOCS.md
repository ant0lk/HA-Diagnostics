# Сбор и скачивание диагностики

1. Установите или обновите дополнение HA-Diagnostics из репозитория проекта. Slug `ha_diagnostics_live` сохранён.
2. Оставьте Protected mode включённым. Укажите `ingress_admin_id` своего администратора в конфигурации дополнения. При пустом значении панель закрыта.
3. Запустите дополнение и откройте веб-интерфейс через Home Assistant.
4. Нажмите «Собрать ZIP-архив». Дождитесь готовности; при необходимости сбор можно отменить.
5. Нажмите «Скачать ZIP». История и журнал событий охватывают последние 24 часа, логи — весь доступный сохранённый период.
6. В `manifest.json` и `README.txt` проверьте пропуски, лимиты и недоступные источники. Перед передачей архива просмотрите его содержимое.

Настройка ChatGPT, MCP, OAuth или Tunnel не требуется. Alpha 4 включает `configuration/`: YAML-настройки HA с подключёнными файлами, сохранённые настройки интерфейса и помощников, data/options интеграций и настройки дополнений из Supervisor API. `configuration/index.json` указывает источники, пути и пробелы. Конфигурация HA подключена в `/homeassistant` только для чтения; исходные файлы не меняются. Сохраняется очищенная JSON-структура, !secret и !env_var не разрешаются, шаблоны не вычисляются, пароли и ключи скрываются. Сырые файлы, secrets.yaml, auth-хранилища, база Recorder, медиа и приватные файлы дополнений не копируются.

Ежедневный автосбор включён по умолчанию в 03:00 по часовому поясу Home Assistant и работает при закрытой панели. В блоке «Ежедневный автоархив» можно изменить время или отключить расписание, затем нажать «Сохранить расписание». Хранятся отдельно последние 7 автоматических и 3 ручных архива без удаления по возрасту. Архивы и настройки доступны после перезапуска. `ARCHIVE_STRUCTURE.txt` содержит название ZIP и дерево всех папок и файлов для нейросети.

На реальной HA OS нужно проверить установку/обновление, Ingress, Linux UID/IPC, доступность API и скачивание большого архива. Локальные тесты используют имитацию источников и не заменяют эту приёмку. Подробнее: `docs/ZIP_EXPORT.md` в исходном проекте.
