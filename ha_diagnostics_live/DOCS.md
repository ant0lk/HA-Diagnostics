# Сбор и скачивание диагностики

1. Установите или обновите дополнение HA-Diagnostics из репозитория проекта. Slug `ha_diagnostics_live` сохранён.
2. Оставьте Protected mode включённым. Укажите `ingress_admin_id` своего администратора в конфигурации дополнения. При пустом значении панель закрыта.
3. Запустите дополнение и откройте веб-интерфейс через Home Assistant.
4. Нажмите «Собрать ZIP-архив». Дождитесь готовности; при необходимости сбор можно отменить.
5. Нажмите «Скачать ZIP». История и журнал событий охватывают последние 24 часа, логи — весь доступный сохранённый период.
6. В `manifest.json` и `README.txt` проверьте пропуски, лимиты и недоступные источники. Перед передачей архива просмотрите его содержимое.

Настройка ChatGPT, MCP, OAuth или Tunnel не требуется. Конфигурационные файлы, секреты, база Recorder и медиа не копируются. Распознаваемые секреты очищаются. Последние 3 готовых архива хранятся до 24 часов и доступны после перезапуска.

На реальной HA OS нужно проверить установку/обновление, Ingress, Linux UID/IPC, доступность API и скачивание большого архива. Локальные тесты используют имитацию источников и не заменяют эту приёмку. Подробнее: `docs/ZIP_EXPORT.md` в исходном проекте.
