# HA-Diagnostics — ZIP diagnostics 1.0.0-alpha.2

Дополнение собирает доступную диагностику Home Assistant в один ZIP. Откройте веб-интерфейс, нажмите «Собрать ZIP-архив», дождитесь завершения и скачайте файл. История и события включаются за последние 24 часа, логи — за всё время, доступное через Supervisor.

В архиве: логи Core, Supervisor, хоста, системных служб и установленных дополнений, сведения о системе и сети, текущие состояния, реестры, доступная диагностика интеграций. `manifest.json` показывает результаты чтения, пробелы и SHA-256, `README.txt` — краткий отчёт. Если источник недоступен, остальные данные всё равно собираются.

MCP, OAuth и Tunnel для ZIP не требуются. Protected mode оставьте включённым. В options укажите проверенный `ingress_admin_id` администратора. Сбор запускается только кнопкой; распознаваемые секреты очищаются до записи. Файлы конфигурации, `.storage`, база Recorder и медиа не копируются. Токен Supervisor остаётся только у отдельного credential worker. Старый slug `ha_diagnostics_live` сохранён для обновления установленного дополнения.

Хранятся последние 3 ZIP до 24 часов; скачивание работает и после перезапуска. Предельные объёмы и ошибки отражаются внутри архива. Подробнее: `../docs/ZIP_EXPORT.md`.

Этот каталог содержит полный Docker build context для amd64/aarch64. Локальные проверки выполняются с имитацией HA API; сборка, Linux изоляция, чтение реальных API и скачивание через HA Ingress требуют приёмки на реальном стенде.
