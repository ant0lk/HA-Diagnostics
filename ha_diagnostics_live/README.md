# HA-Diagnostics — ZIP diagnostics 1.0.0-alpha.5

Alpha 5 добавляет трассы автоматизаций/скриптов, Repairs, уведомления, System Health/System Log, диагностику устройств, этажи/метки, задания/репозитории Supervisor, службы хоста, диск/swap и статистику Recorder (до 64 рядов за 7 дней). В configuration входят используемые blueprints, YAML-панели и буквальные Jinja-импорты без исполнения. system/overview.json и .txt содержат паспорт хоста: ресурсы ядра отдельно от контейнерных лимитов, версии, оборудование, сеть и дополнения. comparison/ сравнивает настройки, установленные версии и реестры с предыдущим сохранённым ZIP, включая Alpha 4. Недоступные данные и пределы сбора отражаются в manifest; фоновое накопление событий/нагрузки не включено.

Дополнение собирает доступную диагностику Home Assistant в один ZIP. Откройте веб-интерфейс, нажмите «Собрать ZIP-архив», дождитесь завершения и скачайте файл. История и события включаются за последние 24 часа, логи — за всё время, доступное через Supervisor.

В архиве: логи Core, Supervisor, хоста, системных служб и установленных дополнений, сведения о системе и сети, текущие состояния, реестры, доступная диагностика интеграций. Раздел `configuration/` содержит YAML с include/packages, сохранённые настройки интерфейса и помощников HA, data/options интеграций и опции, схему, порты, автозапуск, watchdog дополнений. `configuration/index.json` показывает источники и пути, `manifest.json` — результаты чтения, пробелы и SHA-256, `README.txt` — краткий отчёт. Если источник недоступен, остальные данные всё равно собираются.

MCP, OAuth и Tunnel для ZIP не требуются. Protected mode оставьте включённым. В options укажите проверенный `ingress_admin_id` администратора. Сбор запускается по расписанию или кнопкой; распознаваемые секреты очищаются до записи. Конфигурация HA подключается только для чтения; !secret и !env_var не разрешаются. Сырые файлы, secrets.yaml, auth-хранилища, база Recorder, медиа и приватные файлы дополнений не копируются. Токен Supervisor остаётся только у отдельного credential worker. Старый slug `ha_diagnostics_live` сохранён для обновления установленного дополнения.

Ежедневный автосбор включён в 03:00 по часовому поясу HA; время и включение меняются в панели. Хранятся отдельно последние 7 автоматических и 3 ручных ZIP; скачивание работает и после перезапуска. Предельные объёмы и ошибки отражаются внутри архива. Подробнее: `../docs/ZIP_EXPORT.md`.

Этот каталог содержит полный Docker build context для amd64/aarch64. Локальные проверки выполняются с имитацией HA API; сборка, Linux изоляция, чтение реальных API и скачивание через HA Ingress требуют приёмки на реальном стенде.
