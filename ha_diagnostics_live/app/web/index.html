HA-Diagnostics собирает доступные сведения об установке, помогает сохранить их в архиве и разобраться в причинах ошибок.

Диагностический архив

Логи, конфигурация, сведения о системе и история состояний. Соберите ZIP вручную или настройте ежедневное сохранение.

Подключение ChatGPT

Подключите домашний MCP через Secure MCP Tunnel. Сначала создайте туннель в OpenAI Platform, затем сохраните его параметры здесь.

Ключ сохраняется локально и не показывается повторно. Это ключ транспорта OpenAI, а не токен Home Assistant. Для замены введите новый ключ.

После сохранения перезапустите HA-Diagnostics через страницу приложения в Home Assistant. Затем выберите этот туннель при создании MCP в ChatGPT.

OAuth настраивается отдельно. Сохранение туннеля не включает удалённый доступ и не подтверждает подключение ChatGPT.

Доступ и приватность

Очистка уменьшает раскрытие, но не гарантирует удаление любого неизвестного секрета. Уже отправленные сведения остаются в чате по условиям аккаунта OpenAI. Отзыв действует на следующие вызовы.

OAuth subject владельца подтверждается локально. MCP не имеет права менять настройки.

Журнал обращений

Аудит содержит субъект-псевдоним, tool, решение политики, размер и задержку. Текст чата, запрос поиска и журнал в нём не сохраняются.

Скачать ZIP

Распознаваемые секреты удаляются до записи в архив. В ZIP включается очищенная структура конфигурации. Пароли, ключи, secrets.yaml и база данных HA исключены. configuration/index.json покажет источники настроек и пути файлов; manifest.json — результаты чтения и пробелы. ARCHIVE_STRUCTURE.txt покажет название ZIP и дерево всех его папок и файлов.

ДИАГНОСТИЧЕСКИЙ АРХИВ

Архив

Источники, покрытие, сохранённые материалы и импорт диагностических данных.

Наблюдения с доказательствами

Архив хранится локально. ChatGPT получает только разрешённые очищенные выборки. Наличие записей само по себе не подтверждает полноту интервала.

Покрытие и свежесть

Локальный предпросмотр очистки

Последние 10 очищенных записей собственного архива, до 2000 символов каждая. Проверьте их перед разрешением передачи источника; выборка не гарантирует очистку всех неизвестных секретов.



Источники
Сбор и передача — отдельные разрешения. «Все доступные» превращается в явный список журналов и допустимых сущностей.


Диагностические сущности
Камеры, медиа, геопозиция, данные присутствия и чувствительные домены исключены. Snapshot показывает состояние в момент наблюдения, история Recorder — отдельный источник.


Архив и импорт
Только .log, .txt и .json до 20 MiB. Исходный файл не сохраняется. Сначала проверьте очищенный предпросмотр.

      Диапазоны — ориентировочная оценка. У датчиков доступности зелёный означает наличие связи, красный — её отсутствие. Неизвестные значения и объекты без подходящей шкалы показаны нейтральным цветом.
      
        
      
        
      Давность отсчитывается от последнего отчёта объекта в HA; если это время недоступно — от последнего изменения данных. Через сутки показываются дата и время. Деактивированный объект может не иметь состояния и времени обновления. Спящие устройства обновляются редко: давность сама по себе не означает отключение.

        Сопоставление с Home Assistant
        
      Устройства и связи
      
        
      Сначала выберите соответствующее устройство Home Assistant, затем один из его объектов для проверки доступности. Подбор учитывает название, комнату и тип устройства. В окне подбора можно отключить любой фильтр, чтобы расширить поиск.
      
        
      
        
        
        
      
        
      
          Точное сопоставление по ID
          
      Включайте правило для навыка, который передаёт ID объектов именно этой установки HA. Дополнение свяжет устройства, когда внешний ID Яндекса соответствует существующему объекту HA. Если навык объединяет несколько установок, нужен префикс, отличающий эту установку; без него используйте ручную привязку.
      
          
      
            
            
            
      
            
            
            
            
            
          
      
          
      Подтверждённые предложения и ручные привязки имеют приоритет. Название и комната сами по себе не создают автоматическую связь.
      
        
      
        
      
        
      История событий
      
        
        
      События «онлайн» и «оффлайн», сначала новые. Время соответствует проверке статуса.
      
        
      
        
      
        
        
          
      
            
      Связь с Home Assistant
      
            
      
            
      
            
      
              Фильтры подбора
              
      По умолчанию все включены. Отключите лишние фильтры, чтобы расширить поиск. Название сравнивается с устройством и его объектами и может совпадать частично. Тип определяется по назначению объектов.
      
              
      
                
                
                
              
      
              
      
            
      
            
            
            
            
            
      
            
      
              
              
              
              
              
      
            
      
            
      
            
      У светильника «выключен» означает рабочее состояние. «Недоступно» в HA определяется выбранным объектом; при наличии отдельного датчика связи можно выбрать его.
      
          
      
              

      
  
      Подключение и сбор
      
  
      Сохраняйте историю доступности каждого устройства: когда оно было онлайн, когда обнаружен офлайн и когда связь восстановилась. История включается в каждый новый ZIP.
      
  
      
    
    
    
    
      Токен сохраняется только в дополнении и не включается в ZIP. Оставьте поле пустым, чтобы использовать сохранённый токен. Как получить доступ
      
    
      
      
      
    
      
    
  
      
  
      Сбор работает при закрытой панели. История начинается после подключения. Время перехода определяется с точностью до интервала проверки; короткие отключения между проверками могут остаться незамеченными. Пропуски наблюдения записываются отдельно от офлайна. Названия и идентификаторы устройств в архиве заменяются устойчивыми псевдонимами.
