Архив хранится локально. ChatGPT получает только разрешённые очищенные выборки. Наличие записей само по себе не подтверждает полноту интервала.

Покрытие и свежесть

Локальный предпросмотр очистки

Последние 10 очищенных записей собственного архива, до 2000 символов каждая. Проверьте их перед разрешением передачи источника; выборка не гарантирует очистку всех неизвестных секретов.

Источники
Сбор и передача — отдельные разрешения. «Все доступные» превращается в явный список журналов и допустимых сущностей.
Диагностические сущности
Камеры, медиа, геопозиция, данные присутствия и чувствительные домены исключены. Snapshot показывает состояние в момент наблюдения, история Recorder — отдельный источник.
Архив и импорт
Только .log, .txt и .json до 20 MiB. Исходный файл не сохраняется. Сначала проверьте очищенный предпросмотр.

Подключение ChatGPT
Подключите домашний MCP через Secure MCP Tunnel. Сначала создайте туннель в OpenAI Platform, затем сохраните его параметры здесь.
Ключ сохраняется локально и не показывается повторно. Это ключ транспорта OpenAI, а не токен Home Assistant. Для замены введите новый ключ.
После сохранения перезапустите HA-Diagnostics через страницу приложения в Home Assistant. Затем выберите этот туннель при создании MCP в ChatGPT.
OAuth настраивается отдельно. Сохранение туннеля не включает удалённый доступ и не подтверждает подключение ChatGPT.
Доступ и приватность
Очистка уменьшает раскрытие, но не гарантирует удаление любого неизвестного секрета. Уже отправленные сведения остаются в чате по условиям аккаунта OpenAI. Отзыв действует на следующие вызовы.
OAuth subject владельца подтверждается локально. MCP не имеет права менять настройки.
Журнал обращений
Аудит содержит субъект-псевдоним, tool, решение политики, размер и задержку. Текст чата, запрос поиска и журнал в нём не сохраняются.
