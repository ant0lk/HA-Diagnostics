# HA-Diagnostics — private alpha plugin

Базовый пакет содержит portable `plugin.json` и skill. Он устанавливаем как пакет инструкций, но сам по себе **не содержит зарегистрированное MCP-подключение**. Оно появится только после регистрации действующего сервера в аккаунте владельца.

После реального создания custom MCP server скопируйте технический ID `plugin_asdk_app...` со страницы управления подключением (ID не секрет). `python scripts/package_plugin.py --registered-server-id <реальный_ID>` создаст отдельную персональную поставку с `.app.json` и marketplace. Скрипт валидирует формат, но не удостоверяет существование ID: его нужно проверить в аккаунте.

Для portable клиента вместо зарегистрированного mapping можно передать `--mcp-url https://ваш-домен/mcp`. Это не создаёт custom MCP в ChatGPT. Пакеты не содержат ключей, токенов, hooks или callback URI. Подробнее: `docs/INSTALL.md`.
