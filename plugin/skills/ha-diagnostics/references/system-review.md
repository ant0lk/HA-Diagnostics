# Обзор ошибок

Укажи явные границы суток в timezone HA. По каждой группе: компонент, fingerprint, число повторений, первый/последний случай, затронутые сущности только при известной связи, 1–3 примера evidence.

Покажи baseline того же размера непосредственно перед интервалом и его coverage. Не называй ошибку впервые возникшей по неполному baseline. Заверши ограничениями доступных источников и ручными следующими проверками.
